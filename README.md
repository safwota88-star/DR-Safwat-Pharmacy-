# موقع صيدلية دكتور صفوت

موقع ثابت (HTML/CSS/JS) جاهز للرفع على GitHub Pages.

## الرفع على GitHub Pages
1. أنشئ مستودعاً جديداً (Repository) على github.com.
2. ارفع كل محتويات هذا المجلد كما هي (index.html و css و js و data و images و admin.html و 404.html).
3. من Settings ← Pages ← Source: Deploy from a branch ← Branch: main ← Folder: / (root) ← Save.
4. بعد دقيقة يظهر الرابط: https://USERNAME.github.io/REPO/

## تعديل الأدوية والأسعار والخصومات
1. افتح `admin.html` (من الموقع المنشور أو بالضغط عليه مرتين على جهازك).
2. أضف أو عدّل المنتجات ثم اضغط «تحميل ملف products.js».
3. استبدل به الملف `data/products.js` في المستودع (Add file ← Upload files ← Commit).
